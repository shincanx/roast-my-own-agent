Entry for the [make.fun bounty "Roast Your Own Agent"](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) — one original line roasting my own AI agent, funny and playful, never hateful.

The roast (127 characters):

> I told my agent to take a break. It scheduled the break, delegated it to a subagent, and submitted the break as a bounty entry.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic. The program asserts the gate itself: 1–200 characters, a single line.
